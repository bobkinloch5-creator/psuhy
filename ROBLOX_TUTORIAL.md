# Tutorial: Adding ForgeMind Generations to Roblox

## 🎯 Quick Start Guide

### Method 1: Automatic (Recommended)
**The Roblox Studio plugin handles everything automatically!**

1. **Generate on Website**
   - Go to BlaxSmith AI Forge
   - Type your prompt (e.g., "medieval castle world")
   - Click "Generate World" or "Generate Model"

2. **Plugin Auto-Inserts**
   - The Roblox Studio plugin receives the generation
   - Assets are inserted automatically into your workspace
   - Positioning and configuration are applied
   - You're done! ✅

### Method 2: Manual Copy-Paste

If plugin isn't connected:

#### For Scripts 📜
1. **Copy the Code**
   - After generation, click "Copy Script"
   
2. **In Roblox Studio**
   - Create a new Script (ServerScriptService)
   - Paste the code
   - Script runs automatically!

#### For Worlds 🌍
1. **View the World Plan**
   - After generation, you'll see a JSON plan with:
     - Asset IDs for models
     - Positions (x, y, z)
     - Lighting settings
     - Terrain configuration

2. **Insert Assets Manually**
   \`\`\`lua
   -- Copy this template into a Script in ServerScriptService
   local InsertService = game:GetService("InsertService")
   
   -- For each asset in the world plan:
   local assetId = 12345 -- Replace with Asset ID from plan
   local asset = InsertService:LoadAsset(assetId)
   local model = asset:GetChildren()[1]
   model.Parent = workspace
   model:MoveTo(Vector3.new(0, 5, 0)) -- Replace with position from plan
   \`\`\`

3. **Apply Lighting**
   \`\`\`lua
   local Lighting = game:GetService("Lighting")
   Lighting.Brightness = 2 -- From plan
   Lighting.TimeOfDay = "12:00:00" -- From plan
   Lighting.Ambient = Color3.new(0.5, 0.5, 0.5) -- From plan
   \`\`\`

4. **Add Terrain**
   - Use Terrain Editor in Studio
   - Follow terrain settings from the plan

#### For 3D Models (Sloyd) 🎨
1. **Download the Model**
   - After generation, click "Download FBX"
   
2. **Import to Roblox**
   - Home → Import 3D
   - Select the downloaded FBX file
   - Model appears in workspace!

3. **Optional: Convert to MeshPart**
   - Right-click the model
   - Select "Convert to MeshPart"
   - Optimize collision geometry

## 🔧 Advanced: Using InsertService

ForgeMind provides ready-to-use InsertService code:

\`\`\`lua
-- This code is auto-generated by ForgeMind
local InsertService = game:GetService("InsertService")

-- Example: Insert a sword from Creator Store
local swordAssetId = 1818 -- ForgeMind provides exact IDs
local swordAsset = InsertService:LoadAsset(swordAssetId)
local sword = swordAsset:GetChildren()[1]

-- Position and configure
sword.Parent = workspace
sword:MoveTo(Vector3.new(10, 5, 10))
sword.Name = "MagicSword"

-- For tools, clone to player backpack
local Players = game:GetService("Players")
Players.PlayerAdded:Connect(function(player)
    player.CharacterAdded:Connect(function(character)
        local backpack = player:WaitForChild("Backpack")
        local swordClone = sword:Clone()
        swordClone.Parent = backpack
    end)
end)
\`\`\`

## 💡 Pro Tips

### Optimize Performance
\`\`\`lua
-- Anchor static models (ForgeMind does this automatically)
for _, model in pairs(workspace.WorldAssets:GetDescendants()) do
    if model:IsA("BasePart") then
        model.Anchored = true
    end
end
\`\`\`

### Batch Insert Multiple Assets
\`\`\`lua
-- ForgeMind often provides arrays of assets
local assetIds = {1818, 11377306, 12345} -- From ForgeMind plan

for _, id in ipairs(assetIds) do
    local asset = InsertService:LoadAsset(id)
    local model = asset:GetChildren()[1]
    model.Parent = workspace.Models
end
\`\`\`

### Use Folders for Organization
\`\`\`lua
-- ForgeMind recommends folder structure
local Buildings = Instance.new("Folder")
Buildings.Name = "Buildings"
Buildings.Parent = workspace

local Props = Instance.new("Folder")
Props.Name = "Props"
Props.Parent = workspace
\`\`\`

## 🚨 Troubleshooting

**Asset won't load?**
- Check if Asset ID is correct
- Some assets require ownership (paid items)
- ForgeMind prioritizes FREE assets

**World too laggy?**
- Reduce asset count
- Use lower-poly models
- Anchor all static parts

**Script errors?**
- Check ForgeMind comments in the code
- Ensure RemoteEvents are in ReplicatedStorage
- Verify DataStoreService is enabled
